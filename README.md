# UtaTen Lyrics to PDF

UtaTen(うたてん)の歌詞ページから広告や不要な要素を排除し、A4などの印刷用サイズに最適化されたレイアウトでPDF化・印刷可能にするChrome拡張機能です。

## 機能概要

- **インページ自動印刷最適化**
  拡張機能を実行すると、自動的に現在の画面に対して印刷専用のスタイル（広告、ヘッダー、サイドバーの非表示）が適用され、無駄のないレイアウトでプレビューが開きます。
- **ルビ（ふりがな）の切り替え**
  表示されているふりがなをそのまま出力する「ふりがな付き印刷」と、ルビを除去してプレーンなテキストで出力する「ふりがな無し印刷」を選択可能です。
- **タイポグラフィの最適化**
  印刷に最適な明朝体（Noto Serif JP等）の確実な読み込みを待機し、文字サイズと行間が調整された状態でプリントされます。

## インストール手順

この拡張機能は Chrome Web Store には公開されていないため、以下の手順でローカルから導入してください。

1. 本リポジトリをZIPでダウンロード、または `git clone` します。
2. Chromeブラウザで `chrome://extensions/` を開きます。
3. 画面右上の「デベロッパーモード」をオン（有効）にします。
4. 左上の「パッケージ化されていない拡張機能を読み込む」をクリックし、ダウンロードした本ディレクトリ（`manifest.json` が含まれるフォルダ）を選択します。

## 使い方

1. ブラウザ右上の拡張機能リストのパズルアイコンから、本機能（UtaTen Lyrics to PDF）をピン留めしておくと便利です。
2. [UtaTen](https://utaten.com/) の任意の歌詞ページを開きます。
3. 拡張機能のアイコンをクリックすると、アクションポップアップが表示されます。
4. 目的に応じて「ふりがな付きで印刷」または「ふりがな無しで印刷」のボタンを選択します。
5. 最適化された印刷プレビュー画面が開くので、そのままPDFとして保存するか印刷を実行してください。
