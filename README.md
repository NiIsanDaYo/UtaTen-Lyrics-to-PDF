# UtaTen Lyrics to PDF

UtaTen の歌詞をふりがな付きで PDF 化（印刷）する Tampermonkey スクリプトです。

## 特徴

- 🎵 **ふりがな付き**: ルビを保持したまま歌詞を取得します。
- 🖨️ **きれいな PDF**: 印刷用に整形されたレイアウト（タイトル、アーティスト名、中央揃えの歌詞）で出力します。
- 🛠️ **簡単操作**: 歌詞ページに追加される「歌詞を PDF/印刷」ボタンをクリックするだけ。

## インストール

1. ブラウザ拡張機能 [Tampermonkey](https://www.tampermonkey.net/) をインストールします。
2. [ここをクリックしてスクリプトをインストール](https://github.com/NiIsanDaYo/UtaTen-Lyrics-to-PDF/raw/main/utaten-lyrics-pdf.user.js) してください。

## 使い方

1. [UtaTen](https://utaten.com/) で好きな歌詞ページを開きます。
2. ページ右上に表示される赤い「歌詞を PDF/印刷」ボタンをクリックします。
3. 印刷プレビューが開くので、そのまま PDF として保存するか印刷してください。
